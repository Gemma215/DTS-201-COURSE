# DTS 201 Course

This repository contains my lab session notebook for DTS 201, covering 
exercises from Weeks 1–3.

## Contents

- `labs.ipynb` — A single Jupyter notebook with markdown headings for 
  Class 1, Class 2, and Class 3, each followed by the code exercises 
  completed in that session.

## Tools Used

- Python
- Jupyter Notebook (via VS Code)

## How to Run

1. Clone this repository.
2. Open `labs.ipynb` in VS Code (with the Python and Jupyter extensions installed).
3. Run the cells in order.
